# Architecture

Static site, no build step for JS or CSS. Pages are generated by one Python script. Data is static JSON. The only backend is a Google Apps Script web app in front of a Google Sheet.

## Pages and routes
| URL | Served file | Notes |
|---|---|---|
| `/` | `index.html` | Rank page (same as `/rank`). Canonical and social tags |
| `/rank` | `rank.html` (rewrite) | Rank page |
| `/shortlist` | `shortlist.html` (rewrite) | `noindex`. `?project=<key>` and shared links `&units=id,id` |
| `/privacy` | `privacy.html` (rewrite) | Plain page (no `app.js`). In the sitemap |
| `/archive/analytics` | `archive/analytics.html` (rewrite) | Archived Analytics, `noindex` |
| `/archive/home` | `archive/home.html` (rewrite) | Old home page |
| `/rank.html`, `/shortlist.html`, `/privacy.html`, `/archive/analytics.html`, `/archive/home.html`, `/index.html` | 301 | To the clean path (`/index.html` to `/`) |
| `/analysis`, `/analytics`, `/account`, `/archive/account`, `/archive/dashboard` | 301 | To `/` |

`firebase.json` has `cleanUrls: false` and `trailingSlash: false`, with explicit rewrites and redirects. This keeps `/googled48848b9b3ea2809.html` served directly (cleanUrls would 301 it and break verification). A new page needs a rewrite AND a `.html` redirect (see `runbooks.md`). `dev.js` reads the same `redirects` list from `firebase.json` and serves `<path>.html` for extensionless paths.

Useful query strings on the rank page: `?project=<key>` (choose project), `?rank=1` (rank on load, used by the header tab from other pages), `?legend=<factor>` (open the legend drawer at that entry).

## Script order on generated pages
Head: charset, viewport, theme-color, `google-adsense-account` meta, title, description, robots/SEO tags, icons, Google Fonts (Poppins, Inter), `site.css`, `app.css`.
End of body: `config.js`, `ga.js`, `adsense.js`, `site.js`, then (not on plain pages) `scoring.js`, `legend.js`, `ads.js`, `app.js` (module). The archived Analytics page also loads Chart.js 4.4.1 from jsDelivr with SRI.

## Config switches (`public/js/config.js`)
| Key | Value now | Effect |
|---|---|---|
| `SHEETS_URL` | Apps Script `/exec` URL (ends `...94lPew/exec`) | Where rankings and shortlists go. Empty = nothing is sent, Analytics says "Analytics will appear here soon." |
| `GA_ID` | `G-9ZTH2V44EX` | GA4 measurement id. Empty = GA off |
| `ADSENSE_CLIENT` | `ca-pub-6178711736030963` | AdSense publisher id. Empty = AdSense off. Must match `ads.txt` |
| `ADS_ENABLED` | `false` | Old placeholder ad pop-up and video gate. Keep off |
| `ANALYTICS_ENABLED` | `false` | Analytics tab and button hidden. `true` brings them back (link to `/archive/analytics?project=`) |
| `ANALYTICS_SOURCE` | `'sample'` | Archived Analytics uses `sample_submissions.json` in the browser. `'sheet'` reads `?action=analytics` from the Sheet |

A missing boolean key counts as false. `config.js` loads before every other script. With `DEV_FAKE_SHEETS=1`, `dev.js` replaces `config.js` with `{ SHEETS_URL: '/fake-sheets' }` only.

## Live-host checks
`ga.js` and `adsense.js` load Google scripts only when `location.hostname` is the live host (`mybto.web.app` in the last commit). Local dev and tests never send analytics or load ads. <!-- DOMAIN-SWITCH: update when mybto.sg is primary --> (both checks change to `mybto.sg`)

## Browser storage
localStorage (all reads and writes wrapped in try/catch):
| Key | Written by | Holds |
|---|---|---|
| `project` | `app.js loadProject` | Last project key (JSON string). Also read by `site.js` |
| `flags:<project>` | `app.js persistFlags` | Shortlist, ordered unit ids |
| `mybto:flagcount` | `app.js updateFlagCount` | Count for the Shortlisted button |
| `mybto:uid` | `store.js userId` | Anonymous id, `u` + 24 hex chars |
| `mybto:last:<project>` | `app.js saveRanking` | Last filters and weights (restored on return, floor priority excepted) |
| `mybto:lastrank:<project>` | `app.js rememberRanking` | `{at, desc, ids, ranks, scores, prev}` for the shortlist page |
| `mybto:sent:<project>` | `app.js saveRanking` | Hash of the last ranking sent, to skip identical repeats |

sessionStorage: `mybto:ad-consent` (consent time, set at once while ads are off) and `mybto:unlocked:<project>` (video gate, only with ads on). Window event `mybto:project` tells the header which project is active.

## Security headers (`firebase.json`, source `**`)
- `Content-Security-Policy`: `default-src 'self'`; scripts from self, cdn.jsdelivr.net, www.googletagmanager.com, *.googlesyndication.com, *.doubleclick.net, *.google.com, *.adtrafficquality.google, www.googletagservices.com, *.gstatic.com; styles self + fonts.googleapis.com + `'unsafe-inline'`; fonts self + fonts.gstatic.com; images self, data:, blob:, any https; connect to script.google.com, script.googleusercontent.com, GA hosts, www.google.com and the ad hosts; frames only the ad hosts; `object-src 'none'`, `base-uri 'self'`, `form-action 'self'`, `frame-ancestors 'none'`, `upgrade-insecure-requests`.
- Also `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `Referrer-Policy: strict-origin-when-cross-origin`, `Permissions-Policy` (camera, mic, geolocation, payment, usb, interest-cohort off), `Cross-Origin-Opener-Policy: same-origin-allow-popups` (so ad clicks open), `Strict-Transport-Security: max-age=31536000; includeSubDomains`.
- Caching: `no-cache` on everything, JS/CSS/HTML and `/` (a deploy reaches browsers at once); `/data/**` `public, max-age=3600` plus `X-Robots-Tag: noindex`; `/img/**` `public, max-age=604800, immutable`.
- Adding any third-party script, font, frame or fetch target means widening the CSP. If something shows blank on the live site, check the browser console for CSP violations.

## Unit record (site schema)
Each unit in `public/data/units/<key>.json`: `id` (`<CODE>-<block>-<storey 2 digits>-<unit>`, e.g. `BR-200A-02-101`), `project`, `project_key`, `project_type`, `town`, `block`, `storey`, `unit`, `address`, `flat_type`, `unit_design` (Type 1/Type 2 for 2-Room Flexi, else null), `facing` (NE/SE/SW/NW), `position` (Corner/Corridor), `lift_m` null, `lift_near` false, `chute_m`, `chute_near` (<= 10 m), `roof_access`, `neighbour_m` null, `gt30m`, `opposite_m` null, `opposite_gt30m` (= gt30m), `mrt_name`, `mrt_m`, `mrt_near` (<= 100 m), `wind_open`, `mscp_m`, `mscp_near` (<= 100 m), `mscp_estimated`, `facilities_has`, `fac_has_count`, `facilities_near`, `fac_near_count`, `sample_fields` ([]).
`index.json`: `{sample: false, projects: [{key, name, town, project_type, units, blocks, max_storey, flat_types, housing_types, data_status: "real data"}], flat_types, housing_types}`.

Project codes: KBB Kebun Baru Breeze, KBR Kebun Baru Ridge, BR Berlayar Rise, LC Lakeview Cascadia, SB Sembawang Brook, SP Sembawang Portico, WA Woodgrove Acres.
