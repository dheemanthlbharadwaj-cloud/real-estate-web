# MyBTO (HDB BTO unit ranker)

Load the skill at `.claude/skills/mybto-ops/SKILL.md` before doing anything; read its `references/` files as needed. (opencode also finds it at `.opencode/skills/mybto-ops`, a symlink to the same folder.)

## What this is
- A free, unofficial tool that ranks every sale unit of the HDB June 2026 BTO exercise (7 projects, 6,952 units, real data) by the visitor's own priorities, with a shortlist and share links.
- Static site in `public/` on Firebase Hosting: project `mybto-ce84f`, site `mybto`, live at https://mybto.web.app. Custom domain mybto.sg is being connected (2026-10-15); once live it is the primary address.
- Pages are generated by `pipeline/build_pages.py`. Unit data is published by `pipeline/build_real_data.py` from `pipeline/raw/real/`.
- Rankings and shortlists go to a private Google Sheet through a Google Apps Script web app (`apps-script/`); its URL is `SHEETS_URL` in `public/js/config.js`.
- Google Analytics 4 and Google AdSense Auto ads load on the live host only.

## Golden rules
1. No em dashes (U+2014) and no SVG on the site. The tests check both.
2. No secrets in the repo.
3. Production deploys need explicit human approval. Deploy only with `npx firebase-tools deploy --only hosting:site --project mybto-ce84f --non-interactive`.
4. Never hand-edit generated pages; edit `pipeline/build_pages.py` and run it. Never run `pipeline/make_sample_data.py` (it overwrites real data).
5. Never write test rows to the live Sheet; ask before deleting anything in it. Never delete `public/googled48848b9b3ea2809.html`.
6. Plain, short copy; keep the owner's exact words where given. Never edit the owner's Canva designs.
7. Run `npm test` and `CHROMIUM=<chromium path> node test/e2e.browser.js` (must end `ALL BROWSER CHECKS PASSED`) before committing site changes.
8. Update the skill in the same commit as any website, data or backend change. No force-push; stage files by name.
